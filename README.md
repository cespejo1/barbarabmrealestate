# Barbara B.M. Real Estate

A custom real-estate marketing site built with Next.js 16, React 19, TypeScript, and CSS, matching the core stack used by the Espejo Software website.

## Local development

```bash
npm install
npm run dev
```

## Before launch

Update the contact details and market in `app/site-data.ts`. Replace the sample property imagery and sample listing content with approved MLS data and photography. The current property cards are intentionally labeled as generic marketing examples, not active MLS listings.

Then run:

```bash
npm run lint
npm run build
```
